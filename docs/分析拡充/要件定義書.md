# 要件定義書（分析拡充）

> ステータス：**確定**（2026-10-03。基本設計書の要確認事項は仮決定で実装を開始）。ヒアリング元：[docs/支出分析機能/メモ.md](../支出分析機能/メモ.md)（2026-10-03）
> 前提：支出分析機能（[docs/支出分析機能/](../支出分析機能/)）のフェーズ0〜3（分析画面の円グラフ・推移グラフ・レシート一覧への絞り込み）は実装済み。

---

## 1. 概要

カテゴリだけでは集計が粗く、「食費のうち間食はいくらか」「医療費のうち特定の店舗にいくら払っているか」「友人との支出は何に使っているか」「固定費はいくらか」がわからない。

支出を **内訳・費用区分・相手・支払い先** でも分類できるようにし、分析画面でそれらを組み合わせて集計できるようにする。あわせて、分類のためのマスタを整理し、利用者が登録・編集できる **設定画面** を作る。

## 2. ユーザーストーリー

- 2人が、毎月の支出を「何に（カテゴリ・内訳）」「誰と・誰のために（相手）」「どこで（支払い先）」「固定か変動か（費用区分）」の切り口で見て、どこに多く使っているかを把握する。
- レシート登録のたびに同じ内容を選ぶ手間を減らすため、決まった店舗（例：myTOKYOGAS）では、カテゴリなどが自動で入る。
- 自分しか行かない店舗が相方の選択肢を散らかさないよう、支払い先を自分用に登録できる。

## 3. データの構成

| 何を表すか | 項目 | 付ける単位 | 入力 |
|---|---|---|---|
| 何に使ったか | **カテゴリ** ＞ **内訳**（例：食費 ＞ 外食・自炊・間食） | 明細ごと | 内訳を設定したカテゴリでは必須（1つだけ） |
| 固定か変動か | **費用区分**（固定費／変動費） | カテゴリごと | 不要（カテゴリから自動で決まる） |
| 誰と・誰のため | **相手**（例：A／B／ふたり／友人／実家） | 明細ごと | 今の「目的」を置き換える |
| どこで | **支払い先** | レシートごと | グループ全体／ユーザー別に登録 |
| 誰のお金か | **帰属先**（A／B／共同） | 明細ごと | 変更なし（精算・分析の表示対象に使う） |
| その他のラベル | **タグ** | 明細ごと | 任意・複数選択可。今の「シーン」を置き換える |

## 4. 機能要件

### 4.1 設定画面（新設）

ヘッダーに「設定」を追加し、次の登録画面をまとめる。

| 画面 | 内容 | 登録単位 |
|---|---|---|
| カテゴリ | カテゴリごとの **内訳**（追加・編集・削除）と **費用区分**（固定費／変動費）の設定 | グループ全体 |
| 相手 | 相手の選択肢の管理（4.2節） | グループ全体 |
| タグ | タグの追加・編集・削除 | グループ全体（ユーザー別は作らない） |
| 支払い先 | 支払い先の登録と既定値の設定（4.3節）。今の管理画面の「支払い先管理」をここへ移す | グループ全体／ユーザー別 |

### 4.2 相手

- 今の「目的」を「相手」に置き換える。
- 既定の選択肢：メンバーA・メンバーB（グループのメンバーから自動で表示）、ふたり、友人、実家。
- 既定の選択肢は編集・削除できない。表示・非表示の切り替えだけできる。
- 任意の相手を追加・編集・削除できる。
- 管理者だけが編集できる。管理者以外は閲覧のみ。
- 登録・編集画面のプルダウンだけ、ログイン中のユーザー自身を「自分（A）」と表示する。保存する値は変わらず、一覧・詳細・分析では「A」「B」と表示する。

### 4.3 支払い先

- グループ全体の支払い先と、ユーザー別の支払い先を登録できる。
  - グループ全体：管理者だけが編集できる。管理者以外は閲覧のみ。
  - ユーザー別：登録したユーザー本人だけが編集できる。相方のユーザー別の支払い先は閲覧のみ。
- レシート登録画面の支払い先のプルダウンには、グループ全体と自分のユーザー別の支払い先を出す（相方のユーザー別の支払い先は出さない）。
- 相方のユーザー別の支払い先で登録されたレシートも、一覧・詳細では支払い先名を表示し、分析の支払い先別の集計に含める。
- **既定値**：支払い先ごとに、カテゴリ・内訳・相手・帰属先の既定値を設定できる（どれも任意）。
  - レシート登録・編集画面で支払い先を選ぶと、設定された既定値をすべての明細に入れる（入力済みの欄も上書きする）。
  - 支払い先を選び直したときも、新しい支払い先の既定値で上書きする。新しい支払い先に既定値がない項目はそのまま残す。
  - 後から明細を追加したときも既定値を入れる。入った値は自由に変えられる。
  - OCR（画像の読み取り）で支払い先が入った場合の自動入力は対象外。

### 4.4 タグ

- 今の「シーン」を「タグ」に置き換える。
- 明細ごとに、任意で複数選べる。
- 今回は集計に使わない（一覧・詳細で表示するのみ）。後で集計の対象にする可能性があるため、明細ごとに記録しておく。

### 4.5 カテゴリの整理

- カテゴリ「交際費」を削除する。交際は「相手＝友人」などで表す。
- 内訳を設定したカテゴリでは、レシート登録時に内訳を必ず1つ選ぶ。内訳を設定していないカテゴリでは、内訳の欄を出さない。内訳が1つだけのカテゴリでは、自動で選んだ状態にする。

### 4.6 分析の拡充

- 分析画面の円グラフに次の2つの選択を追加する。
  - **分ける**：カテゴリ／内訳／費用区分／支払い先／相手
  - **絞り込み**：なし／上と同じ項目から1つ（例：カテゴリ＝食費）
- ％の分母は、絞り込み後の支出の合計とする（内訳で分けるときは「内訳なし」も含む）。
- 推移グラフにも同じ絞り込みを使える。
- 内訳表の行から、同じ条件で絞り込んだレシート一覧に移れる（既存の仕組みを広げる）。
- 画面を開いた後の切り替えは、これまでどおりサーバー通信なしで行う。

例

| 知りたいこと | 絞り込み | 分ける |
|---|---|---|
| 食費のうち自炊・外食・間食の割合 | カテゴリ＝食費 | 内訳 |
| 医療費のうち店舗ごとの支出 | カテゴリ＝医療費 | 支払い先 |
| 固定費と変動費の割合 | なし | 費用区分 |
| 固定費の内訳 | 費用区分＝固定費 | カテゴリ |
| 友人との支出は何に使っているか | 相手＝友人 | カテゴリ |
| 食費のうち友人との分 | カテゴリ＝食費 | 相手 |

## 5. 既存機能への影響

- レシート登録・編集画面：目的 → 相手、シーン → タグ、内訳の欄の追加、支払い先の既定値の自動入力、支払い先の選択肢の変更。
- レシート一覧・詳細：目的 → 相手、シーン → タグ、内訳の表示。
- 一括入力・複製登録：目的 → 相手、シーン → タグ、内訳への対応。
- 管理画面：支払い先管理を設定画面へ移す。
- 精算：影響なし（帰属先は変更しない）。
- 分析：「分ける」「絞り込み」の追加。
- 既存データ：目的 → 相手、シーン → タグ、交際費の明細を移し替える（基本設計書で方針を決める）。

## 6. 対象外

- 任意タグの集計（後で追加する可能性あり）
- 絞り込みの複数組み合わせ（足りなければ後で拡張）
- OCR で読み取った支払い先からの既定値の自動入力
- 予算設定・予算進捗（支出分析機能のフェーズ4・5。保留中）

## 7. 完了基準

- 設定画面で、カテゴリの内訳・費用区分、相手、タグ、支払い先（既定値を含む）を要件どおりの権限で登録・編集できる。
- レシート登録・編集画面で、内訳・相手・タグを選べ、支払い先の既定値が要件どおりに入る。
- 分析画面で、4.6節の例をすべて集計でき、内訳表から同じ条件のレシート一覧に移れる。
- 既存のレシートが、移し替えたうえで一覧・詳細・分析・精算で正しく表示される。
- 追加したテスト（単体・結合）と既存テストがすべて通る（E2E はテスト環境の制約により実施せず、手動で確認する）。

## 8. ヒアリングでの決定事項（記録）

| No | 論点 | 決定 |
|---|---|---|
| 1 | 相手と帰属先 | 別の項目として両方持つ |
| 2 | 分類の方式 | カテゴリ ＞ 内訳 の2階層。内訳は明細に1つだけ |
| 3 | カテゴリをまたぐ集計 | カテゴリに費用区分（固定費／変動費）を持たせる。カテゴリに「固定費」を入れる方式は採らない |
| 4 | タグ | 任意・複数。グループ全体のみ。今回は集計しない |
| 5 | 相方のユーザー別の支払い先 | プルダウンには出さないが、表示・集計には含める |
| 6 | 集計の画面 | 「分ける」「絞り込み（1つ）」 |
| 7 | 交際費 | カテゴリから削除 |
| 8 | 呼び方 | 「誰と?・誰のため?」→「相手」、中項目 →「内訳」（どちらも後から変更可） |
| 9 | 内訳の入力 | 内訳を設定したカテゴリでは必須。1つだけなら自動選択 |
| 10 | 支払い先の既定値 | カテゴリ・内訳・相手・帰属先。選ぶたびに全明細へ上書き。既定値のない項目は残す |
