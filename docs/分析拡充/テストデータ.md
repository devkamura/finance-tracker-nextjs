## 2. 集計の計算方法

| ルール | 内容 | このデータでの例 |
|---|---|---|
| 按分 | 支払額が明細の合計と違うときは、支払額を明細の金額（税別の明細は税込に直した金額）の比率で分ける。1円未満は切り捨て、余った円は金額の大きい明細から1円ずつ足す | No.12：44,000＋11,000＝55,000 を支払額 49,500 で分ける → 宿泊 49,500×44,000÷55,000＝39,600、夕食 9,900。<br>No.13：1,521×156÷1,520＝156.1→156、1,521×264÷1,520＝264.1→264、1,521×1,100÷1,520＝1,100.7→1,100。合計 1,520 で1円余るので、金額の最も大きい洗剤に足して 1,101 |
| 税別 | 税別の明細は、明細ごとに税率を掛けて税込にする（1円未満は切り捨て） | No.13：145×1.08＝156.6→156、245×1.08＝264.6→264、1,000×1.10＝1,100 |
| 返金 | 返金のレシートはマイナスで集計する。合計がマイナスになったカテゴリは、円グラフには描かず、表と注意書きに出す | No.17：6月の衣類は −5,000 |
| 表示対象 | 全体＝すべて。ゆうき（共同を含めない）＝帰属先がゆうきの明細。ゆうき（共同を含める）＝それ＋共同の明細の **1/2** | ゆうき（共同を含める）＋ふみ（共同を含める）＝全体 |
| ％ | その行の金額 ÷ 絞り込み後のプラスの行の合計（小数第2位を四捨五入） | 9月は合計 100,000 なので、金額 ÷ 1,000 |
| 費用区分 | 明細ごとには持たず、今のカテゴリの設定で集計する | 学習・自己投資は固定費 |
