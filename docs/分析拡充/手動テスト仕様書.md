# 手動テスト仕様書（分析拡充）

E2Eテストの代わりに、実際の画面を操作して確認する項目。機能追加（F1〜F4）ごとに追記する。
各項目の「結果」欄に OK／NG と気づいた点を記入する。スマホの確認は Chrome の開発者ツールのデバイスモードで行う。

対象：[基本設計書.md](./基本設計書.md)、[詳細設計書.md](./詳細設計書.md)

- ローカル環境（`supabase start` ＋ `npm run dev`）で確認する。マイグレーション（`20261003000002_category_breakdowns.sql`）は適用済み。

## F2：相手・タグ

### 前提

- ローカル環境（`supabase start` ＋ `npm run dev`）で確認する。ローカルの DB には本番のバックアップ（2026-10-03 取得）を入れ、F1・F2 のマイグレーションを流してある（移し替えのリハーサル。件数の確認結果は [詳細設計書.md](./詳細設計書.md) の F2「移し替えの確認」）。
- 本番のデータには、シーンから移ったタグ（朝食・昼食・夕食・間食・飲み物・副業・飲み会・デート・趣味・通院・薬局・宿泊）がすでにある。テストで追加するタグは「テスト」で始まる名前にして、実データと区別する。
- 管理者＝A、一般メンバー＝B。一般メンバーとしての確認（F2-M-06）は、B のアカウントでログインして行う。
- 移し替え前の本番のデータ：目的「生活維持」405件（共同 396・メンバー 9）、「個人」89件、「仕事」2件、「友人」15件、「家族」7件。シーンは120件。
