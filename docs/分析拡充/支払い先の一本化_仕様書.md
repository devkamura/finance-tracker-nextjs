## 1. 概要

支払い先を「グループ全体／自分用」の2つの一覧に分けるのをやめ、グループで1つの一覧にする。

| 項目 | 一本化前 | 一本化後 |
|---|---|---|
| 一覧 | グループ全体／自分用（本人だけ） | グループで1つ |
| 名前の重複 | 相方同士の自分用なら同じ名前を登録できた | グループの中で一意 |
| プルダウンに出すか | 非表示フラグ（グループ共通） | メンバーごとの表示／非表示 |
| 既定値 | 支払い先ごとに1セット | 共通の既定値＋メンバーごとの自分用の既定値 |
| 既定値の項目 | カテゴリ・内訳・相手・帰属先・タグ | ＋商品名 |
| 編集できる人 | グループ全体＝管理者、自分用＝本人 | メンバー全員（自分用の既定値・表示／非表示は本人だけ） |

---

## 2. 用語

| 用語 | 意味 |
|---|---|
| 共通の既定値 | 支払い先ごとに1セット持つ既定値。支払い先を登録したときに入力した内容。登録後もメンバー全員が変更できる |
| 自分用の既定値 | メンバーが自分の分だけ持つ既定値（共通の既定値の上書き）。一式まるごと持つ（項目ごとには上書きしない） |
| 使う既定値 | 操作しているメンバーの既定値。自分用があれば自分用、なければ共通 |
| 表示／非表示 | メンバーごとに、その支払い先を自分の登録画面のプルダウンに出すか |
| 使用中 | 登録済みのレシートで使われている支払い先。削除できない |

---

## 3. 権限

| 操作 | 管理者 | 一般メンバー | 他グループ |
|---|---|---|---|
| 支払い先の登録（共通の既定値を含む） | ○ | ○ | × |
| 名前・別名の変更 | ○ | ○ | × |
| 削除（使用中は不可） | ○ | ○ | × |
| 共通の既定値の変更（登録後） | ○ | ○ | × |
| 自分用の既定値の作成・変更・削除 | 自分の分だけ | 自分の分だけ | × |
| 表示／非表示の切り替え | 自分の分だけ | 自分の分だけ | × |
| 相方の自分用の既定値・非表示の参照 | ○ | ○ | × |

サーバーアクションと DB（RLS・トリガー）の両方で確かめる。

## 4. 画面（設定 ＞ 支払い先）

コンポーネント：[components/settings/PayeeSettingsManager.tsx](../../components/settings/PayeeSettingsManager.tsx)

### 4.1 一覧

```text
表示 [表示中|非表示|すべて]   既定値 [すべて|自分用|共通]          12件／全30件
────────────────────────────────────────────────────────────
myTOKYOGAS  [使用中]                                   ✏️ 👁 🗑(灰色)
[👤 自分用] 水道光熱費 ＞ ガス／ふたり／共同／商品名「ガス代」
  👥 共通：水道光熱費／―／共同
別名：TOKYO GAS、東京ガス
👤 ふみさんは自分用
```

| 要素 | 内容 |
|---|---|
| 名前 | 自分が非表示にしていれば取り消し線と「（非表示）」 |
| [使用中] | レシートで使われているとき。ゴミ箱は押せない |
| 既定値のバッジ | [👤 自分用]（藍色）／[👥 共通]（灰色）。続けて使う既定値の説明 |
| 共通：… | 自分用のときだけ、共通の既定値も出す（共通に戻すかの判断のため） |
| 別名 | 別名があるとき |
| 〇〇さんは非表示／〇〇さんは自分用 | 相方の設定（変えられない） |
| ✏️ | 編集欄を開く |
| 👁 | 自分の表示／非表示を切り替える |
| 🗑 | 削除（使用中は非活性） |

既定値の説明の形式：`カテゴリ ＞ 内訳／相手／帰属先／タグ 〇〇・〇〇／商品名「〇〇」`。未設定の項目は「―」、すべて未設定は「なし」。

### 4.2 絞り込み

画面の中だけで行い、サーバーには問い合わせない（`filterPayees`）。

| 絞り込み | 選択肢 | 初期値 |
|---|---|---|
| 表示 | 表示中（自分のプルダウンに出す）／非表示（自分が非表示にしている）／すべて | 表示中 |
| 既定値 | すべて／自分用（自分用の既定値を持つ）／共通 | すべて |

- 自分の表示状態・自分用の有無だけで判定し、相方の設定は見ない。
- 編集中の支払い先は、保存して条件から外れても、編集欄を閉じるまで表示する。
- 選択は保存しない（画面を開き直すと初期値に戻る）。

### 4.3 編集欄

| 項目 | 追加のとき | 編集のとき |
|---|---|---|
| 名前 | 入力 | 入力 |
| 既定値 | 入力（共通の既定値になる） | 下表 |
| 別名 | なし（保存後に編集で登録） | 追加・削除（その場で保存） |

編集のときの既定値：

| 状態 | 編集欄（管理者・一般メンバーとも同じ） |
|---|---|
| 共通（自分用なし） | 共通の既定値を編集できる（見出しに「全員に反映」）。「自分用にする」 |
| 自分用 | 自分用の既定値を編集。「共通：…」を表示。「共通に戻す」 |

- 「自分用にする」：共通の値をコピーした状態から編集できる。保存で自分用を作る。
- 「共通に戻す」：保存で自分用を削除する。
- 自分用を持つメンバーが共通の既定値を変えるときは、いったん「共通に戻す」で保存してから編集する。

## 5. 業務ロジック

実装：[lib/receipts/payees.ts](../../lib/receipts/payees.ts)

### 5.1 既定値の自動入力

レシート登録・編集画面で支払い先を選んだとき、明細を追加したとき、画像読み取りで支払い先が選ばれたときに、**使う既定値**（`payeeDefaultsFor`）を明細に入れる（`applyPayeeDefaults`）。

| 項目 | 入れ方 |
|---|---|
| カテゴリ・内訳・相手・帰属先・タグ | すべての明細を上書きする。既定値がない項目は未選択にする |
| 商品名 | **商品名が空（空白だけを含む）の明細にだけ**入れる。入力済み・画像で読めた商品名は消さない。既定値がなければ何もしない |

- 内訳は、内訳の既定値があればそれ、なければカテゴリの内訳が1つだけのとき自動で選ぶ。
- 既定値の内訳がカテゴリに属していない・非表示、相手が非表示、帰属先のメンバーがグループにいない、タグが非表示のときは、その既定値は使わない。
- 登録済みのレシートは、編集画面を開いただけでは変えない（支払い先の欄を変えたときだけ上書き）。

### 5.2 支払い先のプルダウン

- 自分が非表示にしていない支払い先を名前順に出す（見出しで分けない）。
- 編集時に、自分が非表示にしている支払い先が選ばれていれば「〇〇（非表示）」として残し、そのまま保存できる。

### 5.3 店名の照合（手入力・画像読み取り）

グループのすべての支払い先（自分が非表示にしているものを含む）の名前・別名と完全一致（前後の空白は無視）で照合する（`findPayeeByName`）。

| 一致した支払い先 | 手入力 | 画像読み取り |
|---|---|---|
| 自分が表示している | 支払い先だけを設定（既定値は入れない） | プルダウンで選び、既定値を入れる |
| 自分が非表示にしている | 支払い先だけを設定 | 手入力欄に入れ、保存時に支払い先だけを設定（既定値は入れない） |
| なし | 登録外（手入力）のまま保存 | 同左 |

### 5.4 別名

- 別名を追加すると、店名が別名と一致する過去のレシート（支払い先に紐づいていないもの）を、その支払い先に切り替える（`add_payee_alias`）。
- 対象はグループ全員のレシート。精算確定済みの月も含む。切り替えるのは支払い先と店名だけで、明細は変えない。
- 別名を削除しても、切り替え済みのレシートは戻さない。

### 5.5 分析・レシート一覧の支払い先の選択肢

- 見出しで分けず名前順に並べ、最後に「登録外（手入力）」を出す。
- 全員が非表示にしている支払い先は、12か月のレシートで使われているときだけ出す。

## 7. サーバーアクション

実装：[lib/actions/settings/payees.ts](../../lib/actions/settings/payees.ts)。すべて自分のグループの支払い先だけを対象にする。

| 関数 | 権限 | 内容 |
|---|---|---|
| `createPayee` | メンバー | 支払い先と共通の既定値（タグを含む）を登録。全員に表示 |
| `updatePayee` | メンバー | 名前だけを変更 |
| `updatePayeeCommonDefaults` | メンバー | 共通の既定値を変更し、タグを入れ替える |
| `setOwnPayeeDefaults` | メンバー | 自分用の既定値を保存（upsert）し、タグを入れ替える |
| `resetOwnPayeeDefaults` | メンバー | 自分用の既定値を削除（共通に戻す） |
| `setPayeeHidden` | メンバー | 自分の表示／非表示を切り替える |
| `deletePayee` | メンバー | 削除。使用中（23503）は削除できない旨を返す |
| `addPayeeAlias`・`deletePayeeAlias` | メンバー | 別名の追加（過去のレシートの切り替え件数を返す）・削除 |

既定値の入力チェック（`validatePayeeDefaults`）：グループのカテゴリ・内訳・相手・タグ・メンバーと照らし合わせる。非表示の内訳・相手・タグは、新しく選ぶことはできないが、保存済みの値としては残せる。

## 8. 既存データの移行

| 移行前 | 移行後 |
|---|---|
| グループ全体 | 誰も非表示にしていない（全員に表示） |
| 自分用 | 相方だけが非表示（本人だけに表示） |
| 非表示（グループ共通） | 全員が非表示 |
| 既定値 | そのまま共通の既定値 |

相方同士の自分用に同じ名前がある場合は1つに統合する。

- 管理者の方の支払い先と既定値を残す（共通の既定値）。管理者の自分用がなければ、先に登録された方を残す。
- 管理者でない方の既定値（タグを含む）が共通と違うときだけ、その人の自分用の既定値として残す。
- レシート・別名は統合先に付け替える。レシートの店名・明細・更新日時は変えない。
- 表示は、統合前にどちらかを表示していたメンバーには表示する。

確認方法：`supabase/snippets/payee-unify-migration-check.before.sql` → マイグレーション → `payee-unify-migration-check.after.sql` を、移行前までのマイグレーションを適用した確認用 DB で、1つのトランザクションの中で実行し、最後にロールバックする（I-54）。

## 9. 非機能

- 設定画面の絞り込みは、サーバーへの通信なしで行う。
- 既定値の自動入力は画面の中で行う（支払い先の一覧は画面を開いたときに取得済み）。
- 外部 API（Gemini）への通信はない。画像読み取りのテストは読み取り結果を入力として与える。

## 11. 既存機能への影響

- レシート登録・編集：プルダウン、既定値の自動入力（自分用・商品名）
- 一括入力

- レシート一覧の絞り込み、分析の支払い先の選択肢

## 12. 既知の制約

| 内容 | 影響 | 対応案 |
|---|---|---|
| 編集欄では、自分用と共通のどちらか一方しか編集できない | 自分用を持つメンバーが共通を変えるには、いったん共通に戻す必要がある | 必要になったら、編集欄に共通と自分用を並べる |
| 絞り込みの選択を保存しない | 画面を開き直すと初期値（表示中・すべて）に戻る | 必要になったら、ブラウザに保存する |
