# 分析で投資を見分けられるようにする 受け入れテスト仕様書（Issue #49）

対象：[要件定義書.md](./要件定義書.md)。テスト項目は [詳細設計書.md](./詳細設計書.md) 6章。

## 前提

- ローカル環境（Supabase ＋ `npm run dev`）で、ゆうき（管理者）・ふみ（一般メンバー）のアカウントで確認する。
- マイグレーションを当てておく（`supabase migration up`）。
- 確認用のレシート3件（2026年11月）は、テストデータの SQL で入れる（何度流しても同じ3件に入れ替わる。ほかのデータは消さない）：
  ```bash
  PGPASSWORD=postgres psql -h 127.0.0.1 -p 55322 -U postgres -d postgres -f supabase/snippets/investment-dummy-data.sql
  ```

### 確認用のレシート（2026年11月）

| No | 支払い先 | 明細 | 金額 | カテゴリ ＞ 内訳 | 帰属先 |
|---|---|---|---:|---|---|
| 1 | テスト証券（11/25） | NISA 積立 | 30,000 | 投資 ＞ 積立（NISA） | ゆうき |
| 2 | テスト証券（11/20） | 個別株 | 10,000 | 投資 ＞ 個別株 | ゆうき |
| 3 | テストスーパー（11/18） | 食材 | 5,000 | 食費 | ゆうき |

11月に、確認用のレシート以外の支出があるときは、その合計を「X 円」とする（11月がこの3件だけなら X＝0）。

## 確認項目

| No | 操作 | 期待結果 | 結果 |
|---|---|---|---|
| AT-01 | ゆうきで 設定 ＞ カテゴリ を開く | カテゴリの最後に「投資」「保険料」があり、費用区分はどちらも「固定費」。「投資」に内訳「積立（NISA）」（費用区分：固定費（カテゴリと同じ））と「個別株」（変動費）がある | |
| AT-02 | 「食費」の内訳の費用区分のプルダウンを開く | 選択肢は「固定費」「変動費（カテゴリと同じ）」の2つ。初期値は「変動費（カテゴリと同じ）」。説明文に「費用区分は内訳ごとにも選べます」がある | |
| AT-03 | ふみで 設定 ＞ カテゴリ を開く | 内訳の費用区分のプルダウンは押せない（表示だけ） | |
| AT-04 | ゆうきでレシート登録画面を開き、明細のカテゴリを「投資」にする（登録はしない） | カテゴリの選択肢に「投資」「保険料」がある。「投資」を選ぶと内訳（積立（NISA）・個別株）を選べる | |
| AT-05 | 分析画面を開く（円グラフ・当月・全体） | 条件に「投資を含める」のチェックボックスがあり、オフ。円グラフに「投資」の値がなく、合計は X ＋ 5,000 円 | |
| AT-06 | 「投資を含める」をオンにする | 円グラフに「投資」40,000円 が出て、合計は X ＋ 45,000 円。閉じた条件の要約に「投資を含む」が出る | |
| AT-07 | 「投資を含める」をオフに戻し、「絞り込み：カテゴリ＝投資」「分ける：内訳」にする | 「投資を含める」はオンの表示で押せない（「絞り込み・分けるで選択中」）。積立（NISA）30,000円・個別株 10,000円 | |
| AT-08 | 絞り込みを外し、「投資を含める」オン・「分ける：費用区分」にする | 積立（NISA）の 30,000円は固定費、個別株の 10,000円は変動費に入っている | |
| AT-09 | 推移グラフにして、「投資を含める」をオフ／オンにする | 当月の棒がオフで X ＋ 5,000 円、オンで X ＋ 45,000 円 | |
| AT-10 | 「投資を含める」オフ・円グラフで、表の「食費」の行を押してレシート一覧に移る | 絞り込みの表示が「食費・特別費を除く・投資を除く」になる。件数は出るが、合計の金額は出ない。テスト証券のレシートは出ない | |
| AT-10b | 「投資を含める」オフ・推移グラフで11月の棒を押し、「この月のレシートを見る」で一覧に移る | 絞り込みの表示に「投資を除く」が出て、テストスーパーの1件だけが出る（テスト証券は出ない）。「投資を含める」オンで同じ操作をすると、3件とも出る | |
| AT-11 | 一覧で「← 分析に戻る」を押す | 分析画面が、移る前の条件（投資を含めるオフ）で開く。再読み込みしても同じ | |
| AT-12 | 一覧のフィルタで「ユーザー：ゆうき・支払者」を選ぶ | 条件と件数だけが出て、合計の金額は出ない | |
| AT-13 | 設定 ＞ カテゴリで、「投資 ＞ 個別株」の費用区分を「固定費（カテゴリと同じ）」に変え、AT-08 を見直す | 個別株の 10,000円も固定費に入る。確認したら「変動費」に戻す | |
| AT-13b | 「投資」のカテゴリの費用区分を「変動費」に変える | 内訳の費用区分は変わらない（積立（NISA）は「固定費」、個別株は「変動費（カテゴリと同じ）」の表示になる）。確認したら「固定費」に戻す | |
| AT-13c | 「食費」に内訳「テスト」を追加する | 追加した内訳の費用区分は「変動費（カテゴリと同じ）」。確認したら削除する | |
| AT-14 | 精算画面で11月を開く | 3件とも支払者・帰属先がゆうきなので、ゆうきの負担額と実支払額の両方に 45,000円が入り、精算差額には影響しない（11月がこの3件だけなら「精算の必要はありません」） | |
