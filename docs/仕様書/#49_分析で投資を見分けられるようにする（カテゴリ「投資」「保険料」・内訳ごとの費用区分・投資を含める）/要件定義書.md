# 要件定義書：分析で投資を見分けられるようにする（Issue #49）

Issue：[#49 分析で投資を見分けられるようにする（カテゴリ「投資」「保険料」・内訳ごとの費用区分・投資を含める）](https://github.com/devkamura/finance-tracker-nextjs/issues/49)
ブランチ：`feature-i0018-investment-category`（dev から作成）。2026-11-26 確定。

設計は [詳細設計書.md](./詳細設計書.md)、画面での確認は [受け入れテスト仕様書.md](./受け入れテスト仕様書.md)。

## 用語

| 用語 | 意味 |
|---|---|
| 投資 | NISA の積立・個別株の購入など、資産を増やすために口座から出したお金。カテゴリ「投資」で記録する |
| 生活費 | 投資と特別費を除いた支出（固定費＋変動費） |
| 内訳の費用区分 | 内訳ごとに決める固定費／変動費。決めていない内訳はカテゴリの費用区分に従う |

## 背景

家計相談（保険・毎月の積立額・家計の見直し）をしたところ、次のことが分かった。

- NISA の積立を、カテゴリ「その他」の支出として記録していたため、分析画面の月の支出が投資の分だけ多く見えていた（相談では、タグ「投資」で見分けて SQL で除いた）
- 「投資は毎月の給料の中で行うので、支出として数えたい」人（給料から積み立てる）と、「貯金から投資しているので、支出に入れたくない」人（相方は貯金から毎月10万円を NISA に入れている）がいる。どちらにも合うように、投資を含める・除くを切り替えられる必要がある
- NISA の積立は毎月決まった額（固定費）、個別株は買うときだけ（変動費）と、同じ投資でも費用区分が違う。費用区分はカテゴリごとにしか持てないため、内訳ごとに持てるようにする
- 保険料に当たるカテゴリがない（保険料は投資ではなく、固定費の支出）
- レシート一覧の絞り込み中の合計は、一覧のフィルタでは全部（投資・特別費も）を足し、分析画面から来たときは分析の条件に従う。投資の切り替えが加わると、何の合計なのか分かりにくくなる

## ユーザーストーリー

- 分析画面で、投資を除いた生活費の推移を見て、外食などの見直しの効果を確かめたい
- 給料の中でのお金の使い道として、投資も含めた全体を見たいときは、切り替えて見たい
- 毎月の積立と、個別株にいくら使ったかを分けて見たい

## 仕様

1. **カテゴリの追加**：アプリ共通のカテゴリに「投資」と「保険料」を追加する。費用区分の初期値はどちらも固定費（グループの設定で変えられるのは、ほかのカテゴリと同じ）。
2. **内訳ごとの費用区分**
   - 内訳ごとに「固定費」「変動費」を選べる。内訳を作るときは、そのときのカテゴリの費用区分が入る。カテゴリの費用区分と一致している方に「（カテゴリと同じ）」と添えるだけで、カテゴリの費用区分を変えても内訳の費用区分は変わらない（2026-11-26 実装時に変更：最初は「カテゴリと同じ（〇〇）／固定費／変動費」の3つでカテゴリに合わせて変わる案だったが、選択肢が重なり、カテゴリに合わせて変わる仕組みも不要とのことで、内訳が必ず区分を持つ形にした）。既存の内訳には、今のカテゴリの費用区分を入れる。
   - 明細の費用区分は、内訳のある明細は内訳の費用区分、内訳のない明細はカテゴリの費用区分。分析の「分ける」「絞り込み」の費用区分と、レシート一覧への絞り込みの両方で、この決め方を使う。
   - 設定 ＞ カテゴリの内訳の行に、費用区分のプルダウンを付ける。編集できるのは、内訳と同じく管理者。
   - 費用区分を変えると、過去の月も新しい区分で集計される（明細には保存しない。今のカテゴリの費用区分と同じ）。
3. **分析画面の「投資を含める」チェックボックス**
   - 「特別費を含める」と同じ見た目で並べる。**初期値は OFF**（カテゴリ「投資」の明細を除く）。
   - 円グラフ・推移グラフの両方に効く。条件は URL に残し、戻る・再読み込みで元に戻る。
   - 「絞り込み：カテゴリ＝投資」を選んでいる間は、チェックを ON とみなす（ON の表示で押せない）。除くと何も出なくなるため。
   - 「直近12ヶ月の特別費」の合計は、今までどおり特別費の明細をすべて足す（「投資を含める」には関係しない）。
4. **分析画面からレシート一覧への移動**：投資の条件（含める／除く）を引き継ぎ、各レシートの「うち〇〇円」をグラフと一致させる。一覧のフィルタ欄に「投資」は追加しない。
5. **レシート一覧の合計を表示しない**
   - 絞り込み中の表示から「合計」を消し、条件と件数だけにする（一覧はレシートを探す画面とし、合計は分析画面で見る）。
   - 分析画面から来たときは、条件に「投資を除く」「特別費を除く」（除いているとき）も表示する（2026-11-26 実装時に変更：今の「特別費を除く」の表示に揃えた。除く表示がなければ含んでいる）。
   - 各レシートの「うち〇〇円」は残す。
6. **既存データ（マイグレーション）**
   - グループごとに、カテゴリ「投資」の内訳「積立（NISA）」（固定費）と「個別株」（変動費）を作る。
   - タグ「投資」が付いた明細を、カテゴリ「投資」＞内訳「積立（NISA）」に付け替える。精算確定済みの月も含める。金額・帰属先・相手・タグ・特別費は変えない。
7. **精算**：変えない。投資の明細も、今までどおり帰属先に応じて負担額に入る（帰属先・支払者とも本人にしておけば、精算の結果に影響しない。この記録のルールを画面仕様書に書く）。
8. **相談用の SQL・スキル**：`supabase/snippets/fp-consult-export.sql`・`fp-consult-monthly-check.sql` の費用区分を「内訳 → カテゴリ」の順で決める。スキル `japan-fp-advisor` の集計は、カテゴリ「投資」で投資を見分けられるようにする（リポジトリの外）。
9. **文書**：全体仕様書（要件定義書・基本設計書・用語と算出方法・画面仕様書の 03・05・07・10）を更新する。用語と算出方法の5章は「月の生活費＝投資と特別費を除いた支出」に直す。

## 対象外

- 相談用データのダウンロード（相談用テキスト・CSV）
- 収入の記録、資産の残高の記録
- 「絞り込み」での「〇〇以外」の指定
- カテゴリの並び順の変更（「投資」「保険料」は「その他」の後ろに並ぶ）

## 影響

- DB：マイグレーション1本（カテゴリ2件の追加、`category_breakdowns.cost_type` の追加、内訳の作成、タグ「投資」の明細の付け替え）。`seed.sql` にカテゴリ2件を追加。本番リリースではマイグレーションを先に適用する。
- 設定 ＞ カテゴリ（内訳の費用区分）。
- 分析（費用区分の決め方、「投資を含める」、URL の状態、一覧への条件の引き継ぎ）。
- レシート一覧（合計の削除、条件の表示）。
- 精算の計算は変えない。

## 完了基準

1. 設定 ＞ カテゴリで、内訳ごとに費用区分を設定できる。設定した内訳の明細が、分析の「費用区分」でその区分として集計され、一覧への絞り込みでも同じになる。
2. 分析画面の「投資を含める」が OFF（初期値）のとき、カテゴリ「投資」の明細が円グラフ・推移グラフ・一覧の「うち」金額から除かれる。ON にすると含まれる。「絞り込み：カテゴリ＝投資」では ON とみなされる。
3. レシート一覧の絞り込み中に合計が出ない（条件と件数だけ）。
4. 既存のタグ「投資」の明細が、カテゴリ「投資」＞内訳「積立（NISA）」に付け替わっている。精算の金額は変わらない。
5. 追加したテストと既存のテストがすべて通る。
