## 設定画面 機能
### 支払い先登録画面
- 既存の管理画面にある支払い管理画面を移行
- グループ全体 / ユーザー別でそれぞれ登録することができる。
- 支払い先プルダウンに表示リストはグループ全体 + ユーザー別のリスト（相方のは表示されない)
- グループ全体：編集できるのは管理者のみ/ それ以外のユーザーは閲覧のみ
- ユーザー別：ログインユーザーと一致しているユーザーであれば、編集可能・
- 他のユーザー登録リストは閲覧のみ可能。

### 誰と?・誰のため？登録画面
- 誰と?・誰のため？のリストを登録することができる。
- グループ全体のみ
- デフォルト：ユーザー名（A) / ユーザー名（B) / ふたり / 友人 / 実家
- A/Bは自動表示
- デフォルトの表示・非表示切り替え
- デフォルトは編集不可。表示切り替えのみ。
- 任意の「誰と?・誰のため？」を追加・編集・削除可能。
- 管理者以外は本画面・編集不可/閲覧のみ可能。

### タグ
#### レシート登録画面
- 既存のシーン（任意・複数選択可）をタグに変更
- タグは、複数選択可能
- タグは、強制の項目（選択しないとバリデーションエラー発生)と任意の項目を2段にして分けて表示する
- 特定のカテゴリを選択した場合、必須項目のタグが表示される
- 任意のタグは常に表示でいい（後で仕様変更可能性あり)

#### タグ登録画面
- グループ全体とユーザー別に登録できる
- 必須項目と任意項目によって異なる

##### 【必須項目の場合】
- カテゴリ毎に必須のタグを紐づけておく（複数可能）
たとえば、カテゴリの食費を選択したら、必須タグの欄に自炊 / 外食 / 間食 が表示される。
- カテゴリで通信費を選択した場合、強制的に特定のタグを選択された状態にする仕組みもほしい。
たとえば、カテゴリ：通信費を押したら、あらかじめ登録していた「生活インフラ」タグを自動登録する。
