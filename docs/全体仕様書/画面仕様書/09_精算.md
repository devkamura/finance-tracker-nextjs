# 09 精算

## 目的

その月に、2人のどちらがどちらにいくら払えば公平になるかを見て、月ごとに確定する。

## 開き方

ヘッダーの「精算」。

## できること

| 項目・操作 | 内容 | できる人 |
|---|---|---|
| 月の切り替え | 当月を含む直近12か月から選ぶ | メンバー |
| 精算の表 | 2人それぞれの負担額・実支払額・精算差額。項目の「i」で説明を出す | メンバー |
| 精算の結果 | 「〇〇は〇〇に〇〇円支払う」、または「精算の必要はありません」 | メンバー |
| 「確定する」 | 確認のあと、その月の精算を確定する。確定すると、その時点の金額を保存して表示し、その月のレシートは登録・編集・削除できなくなる | 管理者 |
| 「再オープンする」 | 確定した月の確定を取り消す。その月のレシートを変えられるようになり、金額は最新のレシートで計算し直す。もう一度確定すると、金額を上書きする | 管理者 |

- 一般メンバーには、ボタンの代わりに「精算の確定は管理者のみ操作できます。」「再オープンは管理者のみ操作できます。」と出す
- 確定した月には「確定日時」を表示する
- グループのメンバーが2人そろっていないときは「精算を計算するには、グループにメンバーが2人揃っている必要があります。」と出す

## 表示される数字と求め方

詳しくは [用語と算出方法.md](../用語と算出方法.md) 2章・4章。

**前提：明細の金額**

レシートの合計金額（実際に支払った金額）を、明細の金額の比率で分けたもの。ポイントや値引きがあっても、合計金額を超えて負担が計算されることはない。返金のレシートはマイナスにする。

| 数字 | 求め方 |
|---|---|
| 負担額 | 本来その人が負担すべき金額。帰属先がその人の明細は全額、共同の明細は半分を足す |
| 実支払額 | その人が実際にレシートで支払った金額の合計（支払者がその人のレシートの合計金額）。明細の帰属先には関係しない |
| 精算差額 | 実支払額 − 負担額。プラスは多く払っている（返してもらう側）、マイナスは少なく払っている（払う側） |
| 精算の結果 | 精算差額がマイナスの人が、プラスの人へ、その金額を払う |

例：A が共同の食材 10,000円を払い、B が B 個人の日用品 2,000円を払った月

| | A | B |
|---|---:|---:|
| 負担額 | 5,000円 | 5,000円＋2,000円＝7,000円 |
| 実支払額 | 10,000円 | 2,000円 |
| 精算差額 | +5,000円 | −5,000円 |

→ B は A に 5,000円支払う

**端数**：共同の半分で 0.5円が出るときは、負担額を1円未満で四捨五入して表示する。2人の負担額の合計は、実支払額の合計と必ず一致する（画面の注記）。

**負担額がマイナスのとき**：返金などで、その人個人に帰属する支出がマイナスになったため（画面に注記を出す）。

## 注意

- 精算は特別費も含めて計算する
- 確定した月は、保存した金額を表示する（あとからレシートを変えても変わらない。変えるには再オープンする）
