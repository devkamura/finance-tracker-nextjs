# 06 レシート詳細

## 目的

1枚のレシートの内容と画像を確認し、編集・削除する。

## 開き方

レシート一覧の行の「詳細を見る」、特別費の一覧の行。

## できること

| 項目・操作 | 内容 |
|---|---|
| レシートの情報 | 日時、支払い先、合計金額、返金の印、支払者、特別費の印 |
| 「複製」の印 | 相方の分として複製登録されたレシートに出る。押すと「〇〇さんが複製登録したレシートです。内容を確認してください。」と出る |
| 明細 | 商品名・価格と、カテゴリ（内訳）・相手・帰属先・税区分（税別なら税率）・タグ・特別費 |
| レシート画像 | 押すと拡大して見られる |
| 「編集する」 | レシート編集へ |
| 「削除する」 | 確認のあと削除する（画像も削除される） |
| 戻る | 一覧から来たときは「← レシート一覧に戻る」（そのレシートを開いた状態の一覧へ）、特別費の一覧から来たときは「← 特別費の一覧に戻る」 |

## 表示される数字

| 数字 | 求め方 |
|---|---|
| 合計金額 | 登録した合計金額（実際に支払った金額） |
| 明細の価格 | 入力した金額のまま（税別なら税抜きの金額） |

## 注意

- 精算を確定した月のレシートは、「この月の精算は確定済みのため、編集・削除できません。変更するには管理者に再オープンを依頼してください。」と出し、編集・削除できない
