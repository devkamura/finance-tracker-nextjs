# 10 設定 ＞ カテゴリ

## 目的

カテゴリごとに、内訳（例：食費 ＞ 外食・自炊・間食）と費用区分（固定費／変動費）を決める。

## 開き方

ヘッダーの「設定」（最初にこの画面が開く）。設定のタブ：カテゴリ／相手／タグ／支払い先。

## できること

カテゴリ自体（食費・日用品・衣類・ファッション・交通費・通信費・賃料・水道光熱費・娯楽・宿泊・旅行・医療費・学習・自己投資・その他・投資・保険料）は、追加・削除できない。

| 項目・操作 | 内容 |
|---|---|
| 費用区分 | カテゴリごとに「固定費」「変動費」を選ぶ |
| 内訳の追加 | 「内訳を追加（例：外食）」に入力して「追加」 |
| 名前を変更 | 内訳の名前を変える |
| 表示する／非表示にする | 非表示にした内訳は、レシート登録の選択肢に出なくなる（すでに付いている明細はそのまま） |
| 削除 | レシートで使われている内訳は削除できない（ボタンが押せず「登録済みのレシートで使われているため削除できません。非表示にしてください。」と出る） |
| 内訳の費用区分 | 内訳ごとに「固定費」「変動費」を選ぶ。カテゴリの費用区分と一致している方には「（カテゴリと同じ）」と添えてある（表示だけ）。カテゴリの費用区分を変えても、内訳の費用区分は変わらない |

- 同じカテゴリの中で、同じ名前の内訳は作れない
- 内訳を設定したカテゴリでは、レシート登録で内訳の選択が必須になる
- 支払い先の既定値で使われているだけの内訳は削除でき、その既定値は「設定しない」に戻る

## 誰ができるか

- 閲覧はメンバー全員。編集は**管理者だけ**（一般メンバーには「カテゴリの設定は管理者のみ編集できます。」と出す）

## 数字への影響

- 費用区分の初期値は、賃料・水道光熱費・通信費・投資・保険料が固定費、それ以外が変動費。内訳を作ると、そのときのカテゴリの費用区分が入る
- カテゴリ「投資」には、内訳「積立（NISA）」（固定費）と「個別株」（変動費）が最初から用意されている（2026-11-26 時点のグループ。新しく作ったグループでは自分で作る）
- 明細の費用区分は、内訳の費用区分 → カテゴリの費用区分の順に決まる
- 費用区分は分析の「費用区分」で使う。変えると、**過去の月の集計も新しい区分**で表示される
