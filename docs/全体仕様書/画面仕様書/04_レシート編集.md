# 04 レシート編集

## 目的

登録済みのレシートの内容を直す。

## 開き方

レシート詳細の「編集する」。

## できること

[03_レシート登録.md](./03_レシート登録.md) と同じ項目を変えられる。登録との違いは次のとおり。

| 違い | 内容 |
|---|---|
| 支払者 | 変えられる（メンバーのどちらかを選ぶ） |
| 開いたとき | 保存済みの内容を表示する。支払い先の既定値で上書きはしない（支払い先を選び直したときだけ上書きする） |
| 自分が非表示にしている支払い先 | そのレシートで選ばれていれば「〇〇（非表示）」として残り、そのまま保存できる |
| 画像 | 今の画像を表示する。新しい画像を選ぶと差し替わる |
| 相方の分の同時登録 | 出ない |
| ボタン | 「更新する」。更新するとレシート詳細に戻る |
| 戻る | 「← レシート詳細に戻る」 |

## 注意

- 精算を確定した月のレシートは編集できない。また、確定した月の日時には変えられない
- 内訳のあるカテゴリの明細で内訳が空のもの（内訳を作る前に登録したもの）は、保存するときに内訳を選ぶ必要がある
- 複製で作られたレシートの「複製」の印は、編集しても消えない
