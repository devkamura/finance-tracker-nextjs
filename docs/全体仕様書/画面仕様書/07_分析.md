# 07 分析

## 目的

何に・誰と・どこでお金を使っているか、月ごとにどう変わっているかを見る。

## 開き方

ヘッダーの「分析」。

## 画面の構成

### グラフの種類

「円グラフ」「推移グラフ」を切り替える。

### 条件

開閉できる欄。閉じているときも、今の条件（例：「全体 ／ 食費 ／ 内訳で分ける ／ 特別費を含む」）を表示する。

| 条件 | 内容 |
|---|---|
| 表示対象 | 「全体」または「メンバー」 |
| 共同を含める（1/2） | 表示対象がメンバーのときだけ出る。オンにすると、帰属先が共同の明細を半分だけ含める。初期値はオフ |
| 特別費を含める | 初期値はオフ（特別費の明細を除く）。「絞り込み」「分ける」で特別費を選んでいる間は、常に含める（チェックはオンの表示で押せない） |
| 絞り込み | グラフの対象にする支出を、1つの項目の値で絞る。項目はカテゴリ・内訳・費用区分・支払い先・相手・特別費。「なし」はすべての支出 |
| 分ける | 円グラフだけ。対象の支出を何ごとに区切るか。項目は絞り込みと同じ |

例

| 知りたいこと | 絞り込み | 分ける |
|---|---|---|
| 食費のうち自炊・外食・間食の割合 | カテゴリ＝食費 | 内訳 |
| 医療費の店ごとの支出 | カテゴリ＝医療費 | 支払い先 |
| 固定費と変動費の割合 | なし | 費用区分 |
| 友人との支出は何に使っているか | 相手＝友人 | カテゴリ |
| 旅行などを除いたふだんの支出 | なし（特別費を含めない） | カテゴリ |

### 円グラフ

- 月を選ぶ（前の月・次の月、または一覧から。当月を含む直近12か月）
- 選んだ月の支出を、「分ける」の値ごとに円グラフと表で表示する
- 表の行を押すと、同じ条件（月・表示対象・絞り込み・その値）で絞り込んだレシート一覧に移る
- その月に支出がないときは「この月の支出はありません。」（絞り込み中は「この月の〇〇の支出はありません。」）

### 推移グラフ

- 直近12か月の月ごとの金額を棒で、前月比を折れ線で表示する（前月比 100% の位置に基準線）
- 棒を押すと、その月の金額と前月比を表示し、「この月のレシートを見る →」でその月のレシート一覧に移る
- 注意事項：当月は月の途中の金額であること、いちばん古い月は前月比がないことなどを表示する

### 直近12ヶ月の特別費

グラフの下に「直近12ヶ月の特別費 〇〇円 ＞」を表示する（0円のときは出さない）。押すと特別費の一覧へ。

## 表示される数字と求め方

すべての金額は、次のルールで求める（詳しくは [用語と算出方法.md](../用語と算出方法.md) 2〜3章）。

1. **レシートの合計金額を、明細の金額の比率で分ける**。ポイントや値引きの分は、明細の比率で差し引かれる。税別の明細は税込にしてから比率を出す（1円未満は切り捨て）
2. **返金のレシートはマイナス**として足す
3. **表示対象で重みを付ける**

   | 表示対象 | 自分の明細 | 共同の明細 | 相方の明細 |
   |---|---|---|---|
   | 全体 | 全額 | 全額 | 全額 |
   | メンバー（共同を含める：オン） | 全額 | **半分** | 含めない |
   | メンバー（共同を含める：オフ） | 全額 | 含めない | 含めない |

   - 「誰が払ったか」ではなく「誰の負担か（帰属先）」で分ける
   - 共同の半分で 0.5円が出たときは、そのまま「375.5円」のように表示する
4. **特別費を含めない設定なら、特別費の明細を除く**
5. 月は、レシートの日時の月で決める

| 数字 | 求め方 |
|---|---|
| 円グラフの表の金額 | 選んだ月の、その値に当たる明細の金額（上のルール）の合計 |
| 円グラフの表の割合 | その値の金額 ÷ プラスの値の金額の合計（小数第1位まで） |
| 〇〇の合計（円グラフの上） | 選んだ月の、絞り込みに当てはまる明細の金額の合計。絞り込みがなければ「合計」 |
| 推移グラフの棒 | 各月の、絞り込みに当てはまる明細の金額の合計 |
| 前月比 | 当月 ÷ 前月 × 100（小数第1位まで）。いちばん古い月、前月が0円以下の月、当月がマイナスの月は出さない（「―」） |
| 直近12ヶ月の特別費 | 直近12か月の特別費の明細の金額の合計。表示対象に合わせるが、「特別費を含める」や絞り込みには関係なく出す |

**返金で金額がマイナスになったとき**

- 円グラフ・棒では0として描き、表や数字は実際のマイナスの金額で表示する
- 必ず注意書きを出す：「返金が支出を上回った〇〇は、グラフ上0として表示しています（〇〇 −8,000円）」
- 円グラフでは、さらに「割合は、マイナスの〇〇を除いた合計（〇〇円）に対する値です。実際の合計は〇〇円です。」と出す

**費用区分**：カテゴリごとの設定（[10_設定_カテゴリ.md](./10_設定_カテゴリ.md)）で決まる。設定を変えると、過去の月も新しい区分で集計される。

**支払い先**：登録済みの支払い先ごとに集計する。手入力のままのレシートは「登録外（手入力）」にまとめる。

**内訳**：内訳のない明細は「内訳なし」にまとめる。

## 注意

- 選んだ条件は、レシート一覧に移って戻ってきても、画面を再読み込みしても元のまま
- 分析は精算の確定とは関係なく、いつもレシートから計算する
