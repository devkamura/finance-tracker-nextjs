# 08 特別費の一覧

## 目的

直近12か月に、旅行などの特別費をどのレシートでいくら使ったかを見る。

## 開き方

分析画面のグラフの下にある「直近12ヶ月の特別費 〇〇円 ＞」。

## できること

| 項目・操作 | 内容 |
|---|---|
| 見出し | 期間（例：2025年12月〜2026年11月）と表示対象（例：「全体」「ゆうき＋共同1/2」）。表示対象は分析画面で選んでいたもの |
| 合計 | 下の「表示される数字」 |
| 一覧 | 特別費の明細を含むレシートを、月ごとに新しい順に並べる。各行に「うち特別費 〇〇円」を出し、開くと特別費の明細が通常の表示、それ以外の明細が薄く表示される |
| 行の詳細 | レシート詳細へ。詳細の「戻る」はこの一覧に戻る |
| 「← 分析に戻る」 | 元の分析画面（同じ条件）に戻る |

## 表示される数字

| 数字 | 求め方 |
|---|---|
| 合計 | 直近12か月の、特別費の明細の金額の合計。分析画面の「直近12ヶ月の特別費」と同じ金額 |
| うち特別費 | そのレシートの特別費の明細の金額 |

金額は分析と同じ求め方（合計金額を明細の比率で分け、返金はマイナス、表示対象がメンバーなら自分の明細は全額・共同は「共同を含める」のとき半分）。詳しくは [07_分析.md](./07_分析.md)。

## 注意

- 特別費がないときは「直近12ヶ月の特別費はありません。」と出す
