# 03 レシート登録

## 目的

1回の買い物（レシート）と、その中身（明細）を記録する。

## 開き方

ヘッダーの「家計簿」、またはレシート一覧の「新しいレシートを登録」。ログイン後に最初に開く画面。

## 画面の構成

### レシート画像

| 項目・操作 | 内容 |
|---|---|
| 画像の選択 | レシートの写真を選ぶ。選んだ画像はレシートに保存される |
| 「画像から読み取る」 | 確認のあと、画像から支払い先・日時・合計金額・明細（商品名・価格）を読み取って、下のフォームに入れる。読み取った内容は登録する前に必ず確認する |

- 読み取りは外部のサービスを使うため、押す前に「画像を読み取りますか？」と確認を出す
- 読み取った明細は「税別」として入る。税率は商品名から推定した値（8%／10%）が入るが、変えられる
- 読み取った支払い先名が、登録済みの支払い先の名前か別名と一致し、自分のプルダウンに出している支払い先なら、その支払い先を選び、既定値を明細に入れる（[13_設定_支払い先.md](./13_設定_支払い先.md)）

### レシートの情報

| 項目 | 内容 |
|---|---|
| 支払い先 | プルダウンから選ぶ。一覧にないときは「該当なし」を選んで名前を手入力する |
| 日時 | 買い物をした日時。**この日時の月が、一覧・分析・精算の月になる** |
| 支出 / 返金 | 返金を選ぶと、集計ではマイナスとして扱う |
| 合計金額 | **実際に支払った金額**（ポイント・クーポンを使った後の金額）。明細の合計と一致しなくてよい |

- 支払い先を選ぶと、その支払い先の既定値（カテゴリ・内訳・相手・帰属先・タグ）ですべての明細を上書きし、商品名が空の明細には既定の商品名を入れる。既定値がない項目は未選択になる
- 支払い先を手入力した名前が、登録済みの支払い先の名前か別名と一致するときは、「保存時に『〇〇』として保存されます」と表示し、登録時にその支払い先として保存する（明細はそのまま）
- 支払者（実際に払った人）は、登録した本人になる（変えたいときは登録後に編集する）

### レシート項目（明細）

明細ごとに次を入力する。「項目を追加」で増やし、「項目を削除」で減らせる。

| 項目 | 内容 |
|---|---|
| 商品名 | 任意 |
| 価格 | 明細の金額。明細が1つだけのときは「合計と同じ」ボタンで合計金額を入れられる |
| 税区分 | 税込／税別。税別のときは税率（8%／10%）を選ぶ |
| カテゴリー | 何に使ったか |
| 内訳 | カテゴリに内訳を設定しているときだけ出る。そのときは必須。内訳が1つだけなら自動で選ばれる |
| 相手 | 誰と・誰のために使ったか（必須）。自分は「自分（〇〇）」と表示される |
| 帰属先 | 誰の負担か。共同／メンバー。精算の負担額に効く |
| タグ | 任意・複数 |
| 特別費 | 旅行など、ふだんは発生しない支出ならチェックする。分析で除いて見られる |

- 「一括入力」：すべての明細の税区分・税率・カテゴリー・内訳・相手・帰属先・タグ・特別費を、まとめて同じ値にする。項目ごとに「変更しない」を選べる

### 登録

| 項目・操作 | 内容 |
|---|---|
| 「相方（〇〇さん）の分も同じ内容で登録する」 | 2人がそれぞれ同じ買い物をしたときに使う。相方を支払者にした同じ内容のレシートも1件登録する。明細の帰属先は「自分 → 相方」に置き換わり、「相方」「共同」はそのまま（「i」で説明を出す）。相方がいないときは出ない |
| 「登録後、支払い月の一覧画面に移動して確認する」 | オンなら、登録したレシートの月の一覧に移り、そのレシートを開いた状態で表示する。オフなら、この画面のまま続けて登録できる |
| 「登録する」 | 確認のあと登録する。相方の分も登録するときは「相方（〇〇さん）の分も含め2件登録します」と出る |

- 相方の分のレシートには「複製」の印が付き、相方が内容を確かめるきっかけになる。2件は別々のレシートとして編集・削除できる
- 2件のうち片方の登録に失敗したときは、どちらも登録しない

## 入力のチェック

| 内容 | メッセージの例 |
|---|---|
| 合計金額が空 | 合計金額は必須です。 |
| 内訳のあるカテゴリで内訳が未選択、内訳がそのカテゴリのものでない | 項目N: 内訳が不正です。 |
| 税別なのに税率が未選択 | （項目に「税別（税率未選択）」と表示） |

## 注意

- 精算を確定した月の日時では登録できない（管理者に再オープンを頼む）
- 明細の合計と合計金額が違っても、そのまま登録できる。分析・精算では、合計金額を明細の金額の比率で分けて使う（[用語と算出方法.md](../用語と算出方法.md) 2章）
