# 05 レシート一覧

## 目的

月ごとのレシートを見返し、目的のレシートを探す。

## 開き方

ヘッダーの「一覧」。分析画面の表の行・推移グラフの「この月のレシートを見る」からも開く（分析の条件で絞り込んだ状態になる）。

## 画面の構成

### 月の切り替え

- 前の月・次の月に切り替えられる。選べるのは、当月を含む直近12か月
- その月の精算が確定していれば「この月の精算は確定済みです（編集・削除不可）」と表示する（押すと精算の画面へ）

### 絞り込み

開閉できる欄。閉じているときも、使っている条件の数が分かる。条件はすべて同時に満たすものだけを残す。

| 条件 | 内容 |
|---|---|
| ユーザー | 「全員」または「メンバー」。メンバーを選んだら基準を選ぶ |
| 基準：支払者 | そのメンバーが払ったレシート |
| 基準：負担者 | そのメンバーの負担分がある明細（帰属先がそのメンバー）を含むレシート。「共同1/2を含む」をオンにすると、共同の明細も対象にする |
| 期間 | 選んでいる月の中で、開始日〜終了日（片方だけでもよい）。「期間をクリア」で外す |
| キーワード | 支払い先名・商品名の一部で探す（英字の大文字・小文字は区別しない） |

- 「条件をクリア」ですべて外す
- 月を切り替えると、期間だけ外れる（ユーザーとキーワードは残る）
- レシート詳細などに移ってから戻っても、条件は残る

### 絞り込み中の表示

条件と件数を1行に表示し、「解除」で外す。

- 分析画面から来たときは、分析の条件も表示する。特別費や投資を除いているときは「特別費を除く」「投資を除く」と出る（出ていなければ含んでいる）
- **合計は表示しない**。一覧のフィルタだけのときは投資・特別費も含めた全部が、分析画面から来たときは分析の条件どおりの明細が対象になり、何の合計か分かりにくいため。合計は分析画面で見る

### レシートの一覧

- 並び順は「古い順／新しい順」で切り替えられる
- 各行：日時、支払い先、合計金額、返金の印、支払者、「複製」の印、特別費の印（全明細が特別費なら「特別費」、一部なら「特別費あり」）
- 行を開くと、明細（商品名・価格・カテゴリ（内訳）・相手・帰属先・税区分・タグ・特別費）と画像を確認できる。「詳細を見る（画像・編集・削除はこちら）→」でレシート詳細へ

**「うち〇〇 〇〇円」**（明細の条件があるとき）

- そのレシートのうち、条件に当てはまる明細の金額。例：「うち食費 2,000円」
- 金額は分析と同じ求め方（合計金額を明細の比率で分けた後の金額。表示対象がメンバーで共同を含むときは、共同の明細の半分）。そのため、すべての行の「うち」を足すと、分析画面の金額と一致する
- 開いた行では、当てはまる明細を通常の表示、当てはまらない明細を薄く表示する
- 明細の価格は入力した金額のまま表示する。ポイントや値引きがあるレシートでは、明細の価格と「うち」金額が一致しないことがある

### 分析画面から来たとき

- 「← 分析に戻る」で、元の分析画面（同じ条件）に戻る
- 分析画面で選んでいたメンバーは、絞り込みの「負担者」として表示され、変えられる

## 表示される数字

| 数字 | 求め方 |
|---|---|
| 各行の金額 | レシートの合計金額（実際に支払った金額） |
| うち〇〇 | 上記 |

## 注意

- 当てはまるレシートがないときは「この条件に当てはまるレシートはありません。」、その月にレシートがないときは「この月に登録されたレシートはまだありません。」と出す
