# 11 設定 ＞ 相手

## 目的

明細ごとに選ぶ「誰と・誰のために使ったか」の選択肢を管理する。

## できること

一覧には、次の3種類の相手が並ぶ。

| 種類 | 例 | できること |
|---|---|---|
| メンバー | 2人それぞれ | 表示／非表示だけ。名前は管理画面の表示名に連動する |
| 既定 | ふたり・友人・実家 | 表示／非表示だけ |
| 任意 | 会社の同僚 など | 追加（「相手を追加（例：会社の同僚）」）・名前の変更・表示／非表示・削除 |

- 非表示にした相手は、レシート登録の選択肢に出なくなる（すでに付いている明細はそのまま表示・集計する）
- レシートで使われている相手は削除できない（非表示にする）
- 支払い先の既定値で使われているだけの相手は削除でき、その既定値は「設定しない」に戻る

## 誰ができるか

- 閲覧はメンバー全員。編集は**管理者だけ**（一般メンバーには「相手の設定は管理者のみ編集できます。」と出す）

## 数字への影響

- 分析の「相手」で分ける・絞り込むときの値になる
- 相手は精算に影響しない（精算に効くのは帰属先）
