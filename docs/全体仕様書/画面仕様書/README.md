# 画面仕様書

- 最終更新：2026-11-26
- 画面を変える Issue では、完了時にこのフォルダの該当する文書も更新する

## 共通：ヘッダー

すべての画面の上に出る。

| 項目 | 押すと |
|---|---|
| 家計簿（アプリ名） | レシート登録 |
| 一覧 | レシート一覧 |
| 精算 | 精算 |
| 分析 | 分析 |
| 設定 | 設定 ＞ カテゴリ |
| 管理画面（管理者だけに出る） | 管理画面 |

- スマートフォンでは、メニューのボタンで開閉する
- 「メンバー」はグループに入っている2人（管理者と一般メンバー）を指す

## 画面のつながり

```text
ログイン ─→（グループがない）→ グループ作成
   │
   └→ レシート登録 ─→ レシート一覧 ⇄ レシート詳細 ─→ レシート編集
                         ↑
       分析 ─（表・棒から）─┘
        └─（直近12ヶ月の特別費）→ 特別費の一覧 ─→ レシート詳細
       精算
       設定（カテゴリ／相手／タグ／支払い先）
       管理画面
```
