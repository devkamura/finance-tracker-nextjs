# 13 設定 ＞ 支払い先

## 目的

よく使うお店・支払い先を登録し、選んだときに明細へ入る既定値と、店名の別名を決める。

## できること

### 一覧

| 表示 | 内容 |
|---|---|
| 名前 | 支払い先の名前。自分が非表示にしているものには「（非表示）」、レシートで使われているものには「使用中」 |
| 既定値 | 「共通：…」または「自分用：…」（自分用のときは共通の既定値も併せて出す）。例：`食費／登録する人／登録する人` |
| 別名 | 「別名：オーケー長津田店、…」 |
| 相方の状態 | 「〇〇さんは非表示」「〇〇さんは自分用」 |

**一覧の絞り込み**

| 条件 | 選択肢 |
|---|---|
| 表示 | 表示中（自分のプルダウンに出しているもの。初期値）／非表示／すべて |
| 既定値 | すべて（初期値）／自分用／共通 |

- 一覧の上に「N件／全M件」を出す
- 編集中の支払い先は、条件から外れても編集を閉じるまで表示する

### 各行の操作

| 操作 | 内容 |
|---|---|
| 自分のプルダウンに表示する／非表示にする | 自分の登録画面のプルダウンに出すかを切り替える。相方のプルダウン・過去のレシート・分析には影響しない |
| 編集 | 名前・既定値・別名を変える（下の「編集」） |
| 削除 | レシートで使われている支払い先は削除できない |

### 追加・編集

| 項目 | 内容 |
|---|---|
| 名前 | グループの中で重複できない。別名として登録済みの名前も使えない |
| 既定値（任意） | カテゴリ・内訳・相手・帰属先・商品名（空の明細にだけ入ります）・タグ（複数可）。どれも「設定しない」にできる |
| 相手・帰属先の「登録する人」 | 共通の既定値だけで選べる。レシートを入力する人に置き換わる（A が入力すれば A、B が入力すれば B） |
| 「自分用にする」 | 共通の既定値をコピーして、自分だけの既定値として編集する（「登録する人」は自分に置き換えてコピーする） |
| 「共通に戻す」 | 自分用の既定値を削除し、共通の既定値を使う |
| 共通の既定値の編集 | 見出しに「全員に反映」と出る。変えると、自分用を持っていないメンバーの入力に反映される |
| 別名（この店名もこの支払い先にします） | 「別名を追加」で増やせる。同じ別名・支払い先の名前とは重複できない |

**別名を追加したとき**

- 手入力・画像の読み取りで登録した過去のレシートのうち、店名が別名と一致するものを、この支払い先に切り替える（「別名『〇〇』を登録し、過去のレシートN件を『〇〇』に切り替えました。」）
- 精算を確定した月のレシートも切り替える。金額・明細は変わらない
- 別名を削除しても、切り替えたレシートは元に戻らない

## 既定値がレシートにどう入るか

| 場面 | 入り方 |
|---|---|
| 登録・編集画面で支払い先を選んだ・選び直した | 使う既定値（自分用があれば自分用、なければ共通）で、すべての明細のカテゴリ・内訳・相手・帰属先・タグを上書きする。既定値がない項目は未選択にする。商品名は空の明細にだけ入れる |
| 明細を追加した | 選んでいる支払い先の既定値を入れる |
| 画像の読み取りで支払い先が選ばれた | 同上 |
| 手入力の店名が名前・別名と一致した | 支払い先だけを設定する（既定値は入れない） |

- 既定値の内訳・相手・タグが非表示になっている、帰属先のメンバーがいないなど、使えない既定値は入れない
- 「登録する人」の相手は、入力する人の「メンバーの相手」に置き換える。その相手を非表示にしているときは空欄にする

## 誰ができるか

- 登録・名前と別名の変更・共通の既定値の変更・削除は**メンバー全員**ができる
- 自分用の既定値と、表示／非表示は、**自分の分だけ**変えられる（相方の分は見られるが変えられない）

## 数字への影響

- 分析の「支払い先」は、登録済みの支払い先ごとに集計する。手入力のままのレシートは「登録外（手入力）」にまとまる。別名で同じ支払い先にそろえると、分析で1行にまとまる
- 既定値を変えても、登録済みのレシートは変わらない
