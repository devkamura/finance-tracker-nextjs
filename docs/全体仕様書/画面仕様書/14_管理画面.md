# 14 管理画面（ユーザー管理）

## 目的

グループのメンバーを追加・管理する。

## 開き方

ヘッダーの「管理画面」（管理者だけに出る）→「ユーザー管理」。

## できること

| 項目・操作 | 内容 |
|---|---|
| Gmailアドレスでユーザーを追加 | アドレスを入力して「追加」。その人が初めて Google でログインしたときに、このグループのメンバーになる（それまでは「招待中」と表示する）。招待メールは送らない |
| メンバーの一覧 | 表示名・メールアドレス・「管理者」の印・「招待中」の印 |
| 表示名 | メンバー（管理者自身・招待中の人を含む）の表示名を設定する。未設定なら「未設定」 |
| 表示色 | ブルー／レッド／色なし。一覧・分析などでメンバーを見分ける色になる |
| 削除 | 確認のあと、一般メンバー・招待中の人をグループから外す。管理者自身は外せない |

- グループは管理者を含めて2人まで。2人そろっているときは「グループの登録人数上限（管理者含め2人）に達しているため、これ以上ユーザーを追加できません。」と出して、追加できない
- 同じアドレスは重複して追加できない（大文字・小文字、前後の空白は区別しない）
- グループから外しても、その人の Google アカウントは削除されない（別のグループを作る・参加することはできる）

## 誰ができるか

- **管理者だけ**。一般メンバーは表示名を変えられない

## 数字への影響

- 相手の「メンバー」の名前は、ここで決めた表示名になる
